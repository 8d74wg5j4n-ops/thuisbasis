
# 🏡 ThuisBasis

Alles voor thuis, op één plek.

ThuisBasis is onze privé-huishoudapp voor:

- Boodschappen (food en non-food)
- Voorraadbeheer
- Automatische aanvullijsten
- Recepten en maaltijdplanning
- Herinneringen voor producten die bijna op zijn

## Versie
ThuisBasis 0.3

## Gebruik
Een persoonlijke huishoudassistent voor ons gezin.
